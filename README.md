# VELORA MOTO

Premium bilingual motorcycle boutique concept created as a portfolio project. The experience combines an editorial landing page with a filterable catalog, model details, favorites, brand navigation and a consultation flow.

## Highlights

- Responsive English and Russian interface
- Filterable and sortable catalog of 12 premium motorcycles
- Model detail modal with specifications and favorites
- Motion-driven transitions and interactive brand storytelling
- Responsive layouts for mobile, tablet and desktop
- Optimized local WebP assets
- Accessible labels, keyboard-friendly controls and semantic sections

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

The development server is normally available at `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Portfolio note

VELORA MOTO is a fictional concept project. Motorcycle listings, prices, specifications, company details and contact-form behavior are demonstration content and should not be treated as a live commercial offer.
